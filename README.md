# Nekiro_2025
Sekiro Combo Action Practice

세키로식 보스전을 목표로 한 언리얼 엔진 5 3인칭 액션 프로토타입입니다. 
C++ 코드와 블루프린트 자산을 결합해 플레이어와 보스 간의 일대일 전투, 락온, 콤보, 가드 등 핵심 전투 요소를 실험합니다.

## 프로젝트 개요
- **엔진**: Unreal Engine 5 (Enhanced Input, Gameplay Ability 미사용 순수 C++/블루프린트 구성)
- **장르**: 근접 액션 (Souls-like)
- **핵심 목표**: 플레이어/보스의 상호작용과 콤보 액션 구현, 상태 및 UI 시스템 프로토타입

## 주요 C++ 시스템
### 플레이어 캐릭터 (`AK_Player`)
- 향상된 입력 시스템을 이용해 이동, 점프, 대시, 웅크리기, 가드, 공격, 락온 등을 처리합니다.
- 카메라용 스프링암/카메라 컴포넌트, 무기 충돌용 구체 컴포넌트를 생성하고 무기 소켓에 부착합니다.
- `UK_ActionComp`, `UK_StatusComp`, `UK_PlayerAnim`과 연동하여 상태 변화와 애니메이션, UI 업데이트를 담당합니다.

### 액션 컴포넌트 (`UK_ActionComp`)
- 플레이어 무기 충돌을 기반으로 한 콤보 시스템을 관리하며, 입력 유예/리셋 타이머로 다음 콤보 입력을 큐잉합니다.
- 락온 기능을 제공하여 카메라/컨트롤러를 보스에게 회전시키고, 거리 제한을 벗어나면 자동으로 해제합니다.
- 가드 상태 전환 시 델리게이트로 애니메이션 및 이동 속도를 제어합니다.

### 상태 컴포넌트 (`UK_StatusComp`)
- 플레이어/보스 최대 체력 값을 데이터 에셋에서 불러와 현재 체력을 관리합니다.
- 데미지를 받으면 체력을 감소시키고 사망 시 델리게이트를 브로드캐스트해 후속 처리를 트리거합니다.

### 보스 캐릭터 (`AK_Boss`)
- 스태틱 메시 카타나, HP 위젯 컴포넌트, 상태/애니메이션 델리게이트를 초기화합니다.
- 콤보 공격 애니메이션 호출과 실제 데미지 판정을 분리하여 히트 체크를 수행합니다.
- 사망 시 AI 타겟을 해제하고 캡슐 충돌을 비활성화합니다.

### 보스 AI
- `AK_BossAIController`가 비헤이비어 트리를 실행하며 타겟 탐색/공격 지점을 블랙보드에 저장합니다.
- `UBTService_Detect`는 일정 간격으로 플레이어를 탐지하여 타겟으로 설정합니다.
- 공격 태스크/데코레이터가 보스의 사거리 체크, 공격 종료 델리게이트, 회전 등을 담당합니다.

### 데이터 에셋과 UI
- `UK_MovementData`, `UK_CombatData`, `UK_StatusData` 데이터 에셋으로 이동 속도, 콤보 제한 시간, 공격력, 체력 등을 조정할 수 있습니다.
- `UK_MainHUDUI`, `UBossHPWidget`은 체력 바 업데이트 함수를 제공하며, 캐릭터 틱에서 실시간으로 호출됩니다.

## 디렉터리 구조
```
Source/
 ├── Nekiro/AI                # 보스용 비헤이비어 트리 태스크/서비스/데코레이터
 ├── Nekiro/Animation         # 플레이어/보스 애니메이션 인스턴스 및 상태 구조체
 ├── Nekiro/Character         # 플레이어, 보스, AI 컨트롤러 클래스
 ├── Nekiro/Components        # 공통 액션/상태 컴포넌트
 ├── Nekiro/Core              # 게임 모드, 월드 세팅 등 (필요 시 확장)
 ├── Nekiro/Data              # 전투/이동/상태 데이터 에셋 정의
 └── Nekiro/UI                # UMG 위젯 래퍼
```

## 입력 요약 (기본 Enhanced Input 액션 이름)
| 액션 | 설명 |
| --- | --- |
| `IA_Move` | 이동 (WASD/패드 스틱) |
| `IA_Look` | 카메라 회전 |
| `IA_Jump` | 점프 |
| `IA_Dash` | 대시 (구현 예정) |
| `IA_Crouch` | 웅크리기 토글 |
| `IA_Function` | 상호작용 슬롯 |
| `IA_Finish` | 처치 액션 슬롯 |
| `IA_Defense` | 가드 (누름/뗌) |
| `IA_Attack` | 기본 공격 (콤보) |
| `IA_LockOn` | 보스 락온 토글 |

## 확장 아이디어
- 보스 패링/가드 상호작용, 패턴 추가
- 사망 시 컷신, 리트라이 UI 구현
- 멀티 무기/콤보 브랜치 시스템 실험
